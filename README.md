# ICE Academy Website

## 1. Project Overview

The ICE Academy Website is a responsive web application designed to provide information about ICE Academy, its learning opportunities, programmes, partnerships and learner support services.

The platform aims to create a professional online presence for ICE Academy while giving learners an accessible way to explore programmes, access portal pages and learn more about available opportunities.

The website is currently being developed as a frontend prototype, with selected features using demonstration data. Backend integration can be introduced as the project progresses.

## 2. Project Objectives

- Establish a professional online presence for ICE Academy.
- Provide clear information about the academy and its programmes.
- Make learning opportunities easier to discover.
- Improve communication between ICE Academy and prospective learners.
- Provide an accessible and responsive learner portal interface.
- Create a foundation for future backend and database integration.

## 3. Technologies Used

| Technology | Purpose |
|---|---|
| React.js | Frontend development |
| JavaScript | Application functionality |
| CSS3 | Styling and responsive layouts |
| React Router DOM | Page navigation and routing |
| Lucide React | Icons and visual elements |
| Vite | Development server and build tooling |

**Styling approach:** The project uses regular CSS files for page layouts, components, responsive design and visual styling.

## 4. Website Features

### Public Website

- **Home:** Introduces ICE Academy and highlights its purpose.
- **About Us:** Provides information about the academy, its vision, mission and values.
- **Programmes:** Presents learning and development programme areas.
- **Cohorts & Impact:** Provides information about learner development and academy impact.
- **Learning:** Explains learning opportunities and includes searchable frequently asked questions.
- **Partnerships:** Introduces partnership and collaboration opportunities.
- **Enterprise:** Presents enterprise-related opportunities and pathways.
- **Contact Us:** Allows visitors to submit enquiries.

### Learner Portal

- Learner dashboard interface.
- Courses and learning information.
- Certificate overview.
- Certificate preview functionality.
- Navigation between learner portal sections.

**Note:** Certificate records currently use sample data for demonstration. Official certificate management requires verified learner information and backend integration.

## 5. Installation and Setup

### Prerequisites

Before running the project, ensure that you have installed:

- Node.js
- npm
- Git

### Step 1: Clone the repository

```bash
git clone <repository-url>
```

### Step 2: Navigate into the project

```bash
cd ice-project
```

### Step 3: Install dependencies

```bash
npm install
```

### Step 4: Start the development server

```bash
npm run dev
```

Vite will provide a local development URL in the terminal. Open that URL in your browser to view the website.

### Step 5: Build the project

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

## 6. Development Guidelines

To maintain consistency throughout the project:

1. Use React functional components.
2. Keep reusable components organised.
3. Use separate CSS files for page and component styling.
4. Use React Router DOM for navigation.
5. Use Lucide React for consistent icons.
6. Ensure all pages are responsive across desktop, tablet and mobile devices.
7. Use reusable components where appropriate.
8. Keep code readable and properly organised.
9. Avoid introducing unverified programme information, learner statistics or official certificate records.
